# 税理士さんへの質問書（`UD-106` / `UD-401`）

**目的:** 作家さまへのお支払いと消費税の扱いを決める。
**この文書だけで答えられるように書いてある。** コードを読む必要はない。

⚠️ **この文書は質問であって、答えではない。** §4 に私の下調べを書いたが、
**あれは結論ではない。** 税理士さんのご判断が答えである。

⚠️ **ここが決まるまで販売規約を確定しない**（`docs/LEGAL_CLAUSE_DRAFTS.md`
§5）。先に確定すると、あとで改定と作家さまへの再同意が要る。

---

## 1. 事業の形（2026-08-23 決定）

**運営（ストックビジネス合同会社）が自己の名において販売し、作家さまの
作品を取り次ぐ。** App Store・DLsite と同じ形。

|                      |                                                            |
| -------------------- | ---------------------------------------------------------- |
| 売っているもの       | デジタル作品（ブロックチェーン上に記録される会員証・作品） |
| 購入者の契約の相手方 | **運営**。作家さまは契約当事者ではない                     |
| 特商法の販売事業者   | 運営。**作家さまごとの表記は出さない**                     |
| 制作の依頼           | **していない。** 既にある作品をお預かりして売るだけ        |

⚠️ **NFT そのものの法的性質（前払式支払手段・暗号資産のいずれにも
当たらないか）も未確定**で、これも `UD-106` の一部。こちらは弁護士の
領域と思われるが、税務上の取扱いに影響するようであればご指摘いただきたい。

## 2. お金の流れ（実装済みの事実）

```
購入者 ──カード決済──▶ 運営の決済アカウント（Stripe）
                          │
                          │ 月末締め・翌月末払い
                          ▼
                       作家さま（銀行振込）
```

- **Stripe Connect は使っていない。** 代金は**いったん全額が運営の
  アカウントに入る**。決済事業者が作家さまへ直接分配する形ではない
- 作家さまへのお支払額 = **売上総額 − 運営の手数料**
  （手数料率は運営が設定し、**注文時点の率を焼き付ける**）
- **振込手数料は作家さまのご負担**（お支払額から差し引く）。
  ⚠️ これは**設定であって固定ではない**——負担者は運営が変えられる
  （変更は次の締めから。過去の精算には焼き付けてあり、動かない）
- **最低支払額はいまの決定で 1,000 円**（`UD-119`・2026-08-20）。
  満たなければ翌月へ繰り越す。⚠️ これも**設定**で、次の締めから変えられる
- **返金は運営だけが実行する。** 確定済みの精算に載ったご注文が返金に
  なった場合は次回の精算で相殺し、**差し引ききれなければ運営が被る**
  （作家さまへ請求書は出さない）
- **チャージバック（カード会社との争い）に負けた場合も運営が被る**
- 価格は**税込で表示**している。**消費税の内訳は出していない**
  （画面にも CSV にも欄が無い）

## 4. お尋ねしたいこと

### Q1. 源泉徴収は要りますか（いちばん急ぎます）

§1〜§3 の形で、**個人の作家さまへのお支払いに 10.21% の源泉徴収義務が
生じますか。**

- 「商品代金の支払い」と見るなら不要、「原稿料・デザイン料」に当たるなら
  必要、と理解しています。**取次型（自己の名で販売）はどちらに寄りますか**
- 要る場合、**支払調書の提出とマイナンバーの取得が必要になりますか**
- 個人事業主・法人の作家さまでは扱いが変わりますか。変わるなら、
  **属性をどう確かめるべきですか**（いま区別する欄がありません）

> ⚠️ **下調べ（結論ではありません）:** 取次型では「作品という商品を
> 仕入れて売っている」形に近く、源泉徴収は不要という整理があり得ると
> 読みました。ただし確信は持てません。**ご判断をお願いします。**

### Q2. 消費税はどう立てますか

**販売額の全額を運営の売上とし、作家さまへのお支払いを仕入とする**
（総額）のか、**手数料だけを売上とする**（純額）のか。

- §1 の取次型を選んだことで、どちらになりますか
- 課税売上高の見え方が大きく変わるため、**課税事業者となる時期の判断にも
  影響します**

### Q3. インボイス（適格請求書）はどうなりますか

- **作家さまが免税事業者の場合**、運営はお支払いぶんの仕入税額控除を
  受けられますか。経過措置の扱いはどうなりますか
- **運営から購入者へ**適格請求書を発行する必要がありますか。あるなら
  **いつから**必要ですか（いま発行の仕組みはありません）
- 登録番号を**お預かりしているだけで実在確認をしていない**のは問題ですか

### Q4. 税込表示のままでよいですか

いま価格は税込で表示し、**内訳（税抜額・消費税額）を出していません。**
出す必要がありますか。あるなら、購入画面・領収の類・作家さま向けの明細の
どれに必要ですか。

### Q5. 下請法は関係しますか

**制作を依頼していない**（既にある作品を預かって売るだけ）ので対象外、と
理解しています。**この理解でよいですか。**
将来、運営から制作をお願いする形が出てきた場合は変わりますか。

### Q6. お支払いの時期に法令上の縛りはありますか

いまは**月末締め・翌月末払い**です。これで問題ありませんか。

## 5. 答えによって、こちらで何が変わるか

税理士さんのご判断がそのまま作業に落ちます。**先に作らないためにも、
ここを見ていただきたいです。**

| 答え                            | 変わること                                                                                                                                                                                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Q1 = 源泉徴収が要る**         | ⚠️ **いちばん重い。** 支払調書のためにマイナンバーの取り扱いが要り、**「マイナンバーは取り扱わない」方針と両立しません**（`UD-124`）。方針を変えるか、外部の支払代行へ委ねるかを決め直します。精算の計算に徴収額の行が増え、作家さまの属性（個人／法人）を確かめる欄も要ります |
| **Q1 = 要らない**               | いまの実装のままで通ります。販売規約を確定できます                                                                                                                                                                                                                             |
| **Q2 = 総額**                   | 売上レポートの作りは今のままでよい（販売額全体を運営の売上として集計しています）                                                                                                                                                                                               |
| **Q2 = 純額**                   | 売上レポートの集計を作り直します                                                                                                                                                                                                                                               |
| **Q3 = 適格請求書の発行が要る** | 発行の仕組みを新たに作ります（未実装）                                                                                                                                                                                                                                         |
| **Q4 = 内訳が要る**             | 注文に税抜額・消費税額の欄を足します。**過去の注文には遡れません**（注文時点の値を焼き付ける作りのため）——いつから必要かを併せて教えてください                                                                                                                                 |
| **Q5 = 下請法の対象**           | 60 日以内のお支払いが法律上の義務になり、月末締め・翌月末払いの見直しが要ります                                                                                                                                                                                                |
