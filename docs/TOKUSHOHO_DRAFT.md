## 4. 参照元から変えたところ（**理由つき**）

### 4-1. 商品代金以外の必要料金

参照元は「消費税および振込手数料など」でした。

⚠️ **「振込手数料」を外しました。** お支払い方法はカード（Stripe）だけで、
銀行振込の口はありません。**存在しない費用を書くと、購入者は「ほかにも
かかるのかもしれない」と読みます。**

⚠️ **「消費税」の書き方も変えました。** 販売価格が税込である以上、消費税は
「代金以外の必要料金」ではありません。同じ表の中で税込と言いながら
「代金以外に消費税」と書くと、**読んだ方には二重に取られるように見えます。**

⚠️ **「など」を外しました。** 何がかかるか分からない書き方は、表示義務を
果たしたことになりません。

### 4-2. 返品・キャンセルについて — **リンクだけでは足りません**

参照元は「返金ポリシーページをご確認ください」でした。

⚠️ **返品の可否と条件は、この表記の中に書く必要があります。** 別ページへ
案内するだけだと、表示義務を果たしたことになりません。

この仕組みでの実際の扱いは、`docs/REFUND_REQUEST_FLOW.md` と
`docs/SETTLEMENT_AND_REFUND.md` に決めてあります。要点はこうです。

- お客さまからの返金のお申し出を受け付ける口がある
- 最終的な可否は運営が判断する
- 受け取り済み（`claimed`）のデジタル会員証は、通常は取消の対象にしない

**この 3 点を、購入者に分かる言葉で表記の中へ書きました**（§3 の表）。
`docs/SETTLEMENT_AND_REFUND.md` §6 に用意されていた案を土台に、この仕組みの
言葉（デジタル会員証・お受け取り）へ直しています。

⚠️ **文面は下書きです。** 法的な文言は運営と法務のご確認が済むまで確定させません。

### 4-3. 所在地の表記

参照元は「浜松町ダイヤビル２Ｆ」まで続けて書かれていました。読みやすさのため
番地とビル名のあいだに空白を入れています。**中身は変えていません。**

## 5. 販売の形（**決定 2026-08-23**・`UD-111` の本体）

**運営が自己の名において販売し、作家さまの作品を取り次ぐ形**にします
（App Store・DLsite などと同じ型）。

**販売事業者は「ストックビジネス合同会社」** です。

### なぜこの形か

⚠️ **「作家さまが販売者で、運営が販売を代行する」という方針と矛盾しません。**
特商法の「販売業者」は、**購入者と売買契約を結ぶ当事者**を指します。運営が
自己の名で売り、その経済的な結果が作家さまに帰属するなら、購入者から見た
契約相手は運営です。作家さまとの関係は当事者間の内部の話で、**作家契約と
利用規約に書きます。**

そして、これが**実装の事実と一致します**。

| 事実                                                                  | どこで決まっているか            |
| --------------------------------------------------------------------- | ------------------------------- |
| 代金は**運営の決済アカウント**に入る（Stripe Connect を使っていない） | 決済の配線                      |
| 返金を投げられるのは**運営だけ**。作家さまは事実確認に答えるのみ      | `REFUND_REQUEST_FLOW.md` §0     |
| 返金の可否を決めるのも運営                                            | 同上                            |
| 差し引ききれない返金は**運営が被る**                                  | `SETTLEMENT_AND_REFUND.md` §2-4 |
| 運営が手数料を引いて作家さまへ**精算**する                            | 同 §1                           |

### 採らなかった形

**作家さまを契約当事者にする（メルカリ・BASE などの「場の提供」型）。**

⚠️ **作家さまに特商法の表示義務が生じます。** 千ノ国の作家さまは継続的・
反復的に販売されるため事業者性が認められやすく、氏名・住所・電話番号の
表示義務がご本人に生じます。`UD-111` にあった「出品者ごとの表示義務が
生じうる」はこのことです。

⚠️ **表記だけの問題ではありません。** 代金が作家さま口座へ入る形
（Stripe Connect 等）に変えないと、**表示と実態が食い違います**。返金の
責任、チャージバックの負担、精算の位置づけもすべて変わります。

### 揃えておく必要があるもの

⚠️ **3 つの文書で違うことを書くと、争いになったときにいちばん不利な解釈を
されます。** この決定に合わせて、次も同じ形で書いてください。

| 文書                 | 書くこと                                                       |
| -------------------- | -------------------------------------------------------------- |
| 利用規約             | 購入者の契約相手が運営であること                               |
| 作家契約（販売規約） | 運営が自己の名において販売すること／手数料／精算／返金時の扱い |

⚠️ **これらの文面はまだ確定していません。** 法的文言は運営と法務の確認が
済むまで確定・公開しません。

### 税務

⚠️ **この形では、売上は運営のものになります。** 作家さまへのお支払いは費用
です（「場の提供」型なら運営の売上は手数料だけでした）。**消費税の扱いが
変わるので、税理士のご確認をおすすめします。** ここは私の判断できる範囲を
超えます。
