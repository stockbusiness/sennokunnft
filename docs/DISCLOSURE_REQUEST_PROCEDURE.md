# 電話番号の開示請求に答える手順

**版**: 1.0 / **作成**: 2026-08-23 / **対象**: 運営スタッフ

---

## 1. なぜこの手順が要るのか

特定商取引法に基づく表記で、電話番号を **「ご請求があった場合、遅滞なく
開示いたします」** としました（`docs/TOKUSHOHO_DRAFT.md` §2-1）。

⚠️ **これは番号を持たなくてよいという意味ではありません。** 広告面への
掲載を省く代わりに、**求められたら遅滞なく開示する義務**を負っています。

⚠️ **届いた請求に誰も答えられない状態は、番号を空欄にしていたときより
悪い状態です。** 空欄なら「書き漏れ」ですが、こちらは**書いた約束を
守らなかった**ことになります。

---

## 2. 決めておくこと（**運営でご記入ください**）

| 項目                         | 決めた内容                           |
| ---------------------------- | ------------------------------------ |
| 開示する電話番号             | **要記入**                           |
| 一次対応者                   | **要記入**                           |
| 一次対応者が不在のときの代理 | **要記入**                           |
| 返答の期限                   | **要記入**（下の §4 をご覧ください） |

⚠️ **「開示する電話番号」が空欄のままなら、この運用は成り立ちません。**
表記を公開する前に埋めてください。

⚠️ **代理を必ず立ててください。** 一人しかいないと、その方が休んだ日に
届いた請求が止まります。「遅滞なく」は担当者の予定を待ってくれません。

---

## 3. どこへ届くか

特商法の表記に載せている連絡先です。

```
stockbusiness.jp@gmail.com
```

⚠️ **この受信箱を毎営業日、人が見る**必要があります。開示請求は自動で
検知できません（「電話番号を教えてください」と書いてくるとは限らず、
「連絡先を知りたい」「電話で話したい」などの形で届きます）。

---

## 4. いつまでに返すか

法文上は「遅滞なく」です。

⚠️ **「遅滞なく」が具体的に何日かは、法務のご確認をお願いします。**
ここは私の判断できる範囲を超えます。

実務上の目安として、**受信から 1〜2 営業日以内**を上限に置くことを
おすすめします。目安を決めておかないと、忙しい週にそのまま流れます。

---

## 5. 何を返すか（文例）

> ○○ 様
>
> お問い合わせいただきありがとうございます。
> 千ノ国（ストックビジネス合同会社）の電話番号は下記のとおりです。
>
> 電話番号：（開示する番号）
> 受付時間：（受付時間）
>
> ご不明な点がございましたら、このメールにご返信ください。
>
> ストックビジネス合同会社
> 千ノ国 運営

⚠️ **理由を尋ねないでください。** 「何のためにお使いですか」と聞き返すのは、
遅滞なく開示することになりません。

⚠️ **断らないでください。** 開示するかどうかに判断の余地はありません。
そう書いて公開したためです。

⚠️ **このメールに、ほかのお客さまの情報を含めないでください。** 過去の
やり取りを引用して返信するときは、引用部分をご確認ください。

---

## 6. 記録

開示したことを、あとから確かめられるようにします。

| 残すこと       | なぜ                                   |
| -------------- | -------------------------------------- |
| 受け取った日時 | 「遅滞なく」応じたことを示すため       |
| 返した日時     | 同上                                   |
| 返した相手     | 同じ方から重ねて届いたときに分かるため |
| 誰が返したか   | 引き継ぎのため                         |

⚠️ **請求の本文をそのまま長期に保管しないでください。** 個人情報が
含まれます。残すのは上の 4 つで足ります。

⚠️ **この記録は、いまのところ仕組みの中にありません。** 管理画面の
機能ではなく、運営の手元（表計算・チケットなど）で残してください。
**仕組みへ入れるべきかどうかは、件数が見えてから判断すれば足ります。**

---

## 7. やってはいけないこと

- ⚠️ **答えないまま放置する。** 表記に書いた約束を守らないことになります
- ⚠️ **「なぜ必要か」を尋ねて、答えを条件にする**
- ⚠️ **番号を持たないまま「請求があれば開示」と書いておく**
- ⚠️ **一次対応者だけに任せ、代理を決めない**

---

## 8. この手順を見直すとき

| きっかけ                       | 見直すこと                                             |
| ------------------------------ | ------------------------------------------------------ |
| 電話番号が変わった             | §2 の番号と、返信の文例                                |
| 連絡先メールが変わった         | §3 と、特商法の表記そのもの                            |
| 表記を「番号を載せる」に変えた | この手順は不要になる（**消さずに、その旨を書き足す**） |

⚠️ **特商法の表記を変えるときは、この手順も一緒に見直してください。**
片方だけ変えると、書いてあることと運用が食い違います。
